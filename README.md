# Autonomous Transport Robot

An autonomous mobile robot designed to transport small packages between designated locations.

The project focuses on computer vision, embedded programming, navigation and autonomous control using a Raspberry Pi Zero W.

## Project Overview

The robot is designed to follow a black line, recognize ArUco markers at intersections and transport packages to designated destinations based on RFID identification.

### Planned Features

- Line following using camera-based image processing
- Navigation using ArUco markers
- RFID identification of three package types
- Differential drive with two DC motors
- Motor control via an H-bridge
- Package unloading using a servomechanism
- Autonomous navigation and control logic

## Hardware

- Raspberry Pi Zero W
- Camera module
- Two DC motors
- H-bridge motor driver
- RFID reader and tags
- Servomotor

## Software

- Python 3
- Raspberry Pi OS Lite
- Git and GitHub
- Visual Studio Code
